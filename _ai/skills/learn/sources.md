# Learn sources

Start here, then search for anything newer. Surveys come out every year: use the latest edition and cite its year. A source listed here is not proof; verify each fact in the source itself.

| Need | Source | Measures | Limit |
|---|---|---|---|
| Definitions, stage map | [SWEBOK v4](https://www.computer.org/education/bodies-of-knowledge/software-engineering/v4) | 18 knowledge areas (IEEE, 2024) | page returns 403 to tools (2026-11-25): use the books in the vault (`pdftotext`, link the page) |
| Requirements standard | [ISO/IEC/IEEE 29148](https://www.iso.org/standard/72089.html) | requirements processes and quality | page returns 403 to tools: use [arXiv 2502.18617](https://arxiv.org/pdf/2502.18617) (requirement qualities) or [arc42 quality](https://quality.arc42.org/standards/iso-25010) (ISO 25010) |
| Architecture docs | [arc42](https://arc42.org/overview), [C4 model](https://c4model.com), [ADR](https://adr.github.io) | how teams document designs | describe a format, not popularity |
| Patterns, refactoring | [martinfowler.com](https://martinfowler.com) | named patterns and terms | one expert's view |
| Tool and practice trends | [Thoughtworks Technology Radar](https://www.thoughtworks.com/radar) | adopt / trial / assess / hold, twice a year | consultancy opinion |
| Usage | [Stack Overflow Developer Survey](https://survey.stackoverflow.co/), [JetBrains Developer Ecosystem](https://www.jetbrains.com/lp/devecosystem-2025/) | languages, tools, AI use | self-selected samples |
| Open source activity | [GitHub Octoverse](https://github.blog/news-insights/octoverse/) | repositories and contributors | GitHub only |
| Databases | [DB-Engines ranking](https://db-engines.com/en/ranking) | interest score per database | interest, not installs |
| Delivery and DevOps | [DORA reports](https://dora.dev/research/) | delivery performance, AI in teams | DORA-aware teams |
| Cloud native | [CNCF annual survey](https://www.cncf.io/reports/) | Kubernetes and cloud-native adoption | ecosystem sample |
| Operations | [Google SRE books](https://sre.google/books/) | SLOs, monitoring, incidents | Google scale |
| Security | [OWASP Top 10](https://owasp.org/Top10/), [OWASP Top 10 for LLM apps](https://genai.owasp.org/) | most common risks | community ranking |
| Job market | [Indeed Hiring Lab](https://hiringlab.indeed.com/), job ads on LinkedIn | demand trends | postings, not hires |
| Learning paths | [roadmap.sh](https://roadmap.sh) | what a role is expected to know | community-made |
| Interviews | Designing Data-Intensive Applications (Kleppmann); System Design Interview (Xu) | the canonical interview topics | books; cite chapter |
