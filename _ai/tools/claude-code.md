## Claude Code

- Helpers: `scout`, `tester`, `worker`, `reviewer`, `challenger` in `.claude/agents/`; start them with the Agent tool and that exact name. Never `general-purpose`, `Explore` or `Plan`.
- `orchestrator`: start a session on it with `claude --agent orchestrator`; it starts the helpers itself.
- Skills: `.claude/skills/`, each also a slash command with its name (`/plan`, `/delegate`, `/review`, `/data`, `/handoff`, ...).
- Models: cheap = `haiku`, medium = `sonnet`, top = `opus`.
- Guards: deny rules and the guard hook in `.claude/settings.json` (generated by `node _ai/sync.mjs`).
