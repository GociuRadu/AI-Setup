# Kiro

The core rules are in `AGENTS.md`, which Kiro loads on its own; if it is not in your context, read it now.

- Start a helper with the subagent tool and its exact name. The built-in subagents `context-gatherer` and `general-task-execution` are never used.
- A user-level `confluence` skill, if installed, is personal; project pages use `confluence-project`.
