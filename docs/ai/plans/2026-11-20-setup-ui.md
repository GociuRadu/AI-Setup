**Goal:** a small local web page where the user sees and changes the AI setup (tools, profile, hooks, models per helper, skills) and applies it with one click, without the AI chats loading the UI's code.
**Done when:**
- `npm run setup-ui` in `setup-ui/` opens a page on `127.0.0.1` listing helpers, skills and rules counted from `_ai/agents` (minus `_core.md`), `_ai/skills`, `_ai/rules`, and the hooks from a `HOOKS` constant in sync (today 5, 10, 3, 2); a UI test asserts these counts.
- An API test: changing a helper's model and applying changes only `_ai/models.json` or `.ai-device.json` among source files (the rest is generated), and `node _ai/sync.mjs --check` prints `in sync`.
- A sync test writes `perTool` into `.ai-device.json`, runs sync, and reads it back unchanged; an unknown skill name in `skillsOff` fails sync with an error.
- A sync test with Claude + Kiro on: a skill off only for Kiro is in `.claude/skills/` and absent from `.kiro/skills/`; `lang` off only for Claude leaves the Kiro lang hook.
- With default toggles (missing keys = on) `node _ai/sync.mjs --check` stays `in sync` on today's output.
- `node --test "_ai/**/*.test.mjs"` and `npm test` in `setup-ui/` exit 0; a test asserts `setup-ui/` holds no `AGENTS.md`, `CLAUDE.md` or `.github/`.

## Context
- **One source:** `AGENTS.md` + `_ai/` are the source; `node _ai/sync.mjs` generates `.claude/`, `.kiro/`, `.github/` ([sync.mjs:182](../../../_ai/sync.mjs#L182)). The UI edits these same files and runs the sync CLI; it never keeps its own copy.
- **Already config-driven:** profile + tools in `.ai-device.json` ([sync.mjs:301](../../../_ai/sync.mjs#L301)); models in [_ai/models.json](../../../_ai/models.json) plus a per-device `models` block.
- **Device keys get dropped today:** [sync.mjs:447](../../../_ai/sync.mjs#L447) rewrites `.ai-device.json` with only `profile`, `tools`, `models`; new keys must be preserved there and validated in `savedDevice` ([sync.mjs:307](../../../_ai/sync.mjs#L307)).
- **Hooks are emitted in 5 places:** `claudeSettings` ([sync.mjs:137](../../../_ai/sync.mjs#L137)), `kiroHooks` ([sync.mjs:160](../../../_ai/sync.mjs#L160)), every Kiro agent's own `hooks` ([sync.mjs:208](../../../_ai/sync.mjs#L208)), Copilot `guard.json` ([sync.mjs:250](../../../_ai/sync.mjs#L250)), which carries both hooks. Skills: [sync.mjs:218](../../../_ai/sync.mjs#L218). Pinned by tests at `sync.test.mjs:73,95,212`.
- **Guard off (Q4) leaves little behind:** Claude `Read` deny does not stop shell reads; Copilot rules gate only edits; Kiro rules live in `~/.kiro`. The warning says exactly this.
- **Claude + Copilot together** double-fire hooks; sync only warns ([sync.mjs:430](../../../_ai/sync.mjs#L430)); the UI shows the same warning, no block.

## Options: stack
| Option | Pros | Cons | Cost / risk |
|---|---|---|---|
| React + Vite + TypeScript, small Node API | Industry standard, most in-demand | First npm deps and a build step | Medium |
| Svelte + Vite, small Node API | Less code per screen | Smaller job market | Medium |
| VS Code extension (webview) | Inside the editor | Packaging, VS Code only | High |

**Choice (user, 2026-11-20):** React + Vite + TypeScript in `setup-ui/` (own `package.json`, lockfile tracked, `dist/` ignored). API on Node `node:http` serving `dist/`; Apply runs `node _ai/sync.mjs` as a child process (stdout, stderr, exit code shown in the page), one Apply at a time. `npm run setup-ui` = build + serve (renamed from `npm start` by the user); `npm run dev` = Vite with `server.proxy` to the API.

## Risks
| Risk | Effect | Mitigation / rollback |
|---|---|---|
| UI writes a bad value | sync fails for all tools | sync validation rejects it, page shows the error; Git revert of the 2 source files |
| Hostile web page calls the API | config changed silently | Host check, header token, JSON-only, `127.0.0.1` |
| Guard switched off | shell reads of `personal/`/`.env`, SQL writes, PRODUCTION commands unblocked | exact red list + confirm; `--check` prints `guard: off` |
| Apply mid-chat | a chat reads half-written `.claude/` | one Apply at a time; start a new chat after Apply (as today) |

## Challenge
| Objection | Answer | Status |
|---|---|---|
| In-process `main()` hides output, races, caches the module | Run the sync CLI as a child process with a lock | accepted |
| `.ai-device.json` drops new keys; typos in `skills.off` pass silently | Preserve + validate in step 1, test round-trip | accepted |
| Origin check misses DNS rebinding; no dev loop | Host check (step 3); `npm run dev` with proxy | accepted |
