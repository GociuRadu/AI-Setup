# project1

Template for a data-engineering project. This folder is intentionally source-free; add project implementation separately.

## Areas

- `Notebooks/`: exported notebook definitions.
- `pipelines/`: orchestration configuration.
- `TablesDataBase/`: SQL table and procedure setup.
- `local/`: disposable local test environment and runner.
- `tests/`: unit, transformation, and database tests with synthetic fixtures.
- `docs/ai/`: project facts, current context, decisions, and reports.

Start with `.github/copilot-instructions.md` and complete `docs/ai/project.md` before adding project-specific workflows.
